В ранней версии здесь использовались чужие вспомогательные функции.
Сейчас они заменены местными. Ниже прежние сведения об авторах.

# Взятые фрагменты

* Underscore 1.13.7: sample.js (перемешивание фактов) и random.js (выбор окна и задержек).
  https://github.com/jashkenas/underscore/tree/1.13.7/modules
* Just, Eric Nolte и Angus Croll: function-debounce/index.cjs. Задержка перестроения фона после resize.
  https://github.com/angus-c/just/tree/master/packages/function-debounce
* Color 4.2.3, Heather Arthur и участники: luminosity, contrast, maxfn из index.js.
  Расчёт контраста темы и предел счётчика чебупелей.
  https://github.com/Qix-/color/blob/4.2.3/index.js
* escape-goat 4.0.0, Sindre Sorhus: _htmlEscape из index.js. Экранирование карточек и RSS при сборке.
  https://github.com/sindresorhus/escape-goat/blob/v4.0.0/index.js

Все четыре проекта под MIT. Полные лицензии лежат в корне и входят в сборку.
Скачанные новые исходники и SHA-256 лежат в Инструменты/vendor. Just скачан из master, точные байты сохранены.
Полные пакеты в сайт не добавлялись. Адаптации перечислены у соответствующих функций.
Прочая логика сайта остаётся своей. Эти ссылки не означают, что весь сайт написал кто-то из перечисленных авторов.


## Сверка с другими реализациями

Это ссылки для сравнения и чтения исходников. Реально перенесённые фрагменты перечислены выше.

* Похожая реализация: [Turbo/Bardo](https://github.com/hotwired/turbo/blob/main/src/core/bardo.js). Сохранение живого DOM между переходами. Ссылка рядом с кодом в app-shell.js.
* Похожая реализация: [iframe-resizer](https://github.com/davidjbradshaw/iframe-resizer). Размер iframe по содержимому. Ссылка рядом с кодом в guestbook.js.
* Похожая реализация: [weizhenye/Danmaku](https://github.com/weizhenye/Danmaku). Летающие комментарии, DOM-движок. Ссылка рядом с кодом в danmaku.js.
* Похожая реализация: [htmx hx-trigger](https://github.com/bigskysoftware/htmx/blob/v2.0.4/www/content/attributes/hx-trigger.md). Периодический опрос без WebSocket. Ссылка рядом с кодом в chat.js.
* Используемый API: [MDN Page Visibility](https://github.com/mdn/content/blob/main/files/en-us/web/api/page_visibility_api/index.md). Остановка фоновой работы в скрытой вкладке. Ссылка рядом с кодом в cursor-motion-v2-20261021.js.
* Похожая реализация: [emoji-picker-element](https://github.com/nolanlawson/emoji-picker-element). Выбор значка и поиск по списку. Ссылка рядом с кодом в guestbook.js.
* Используемый API: [CPython hmac](https://github.com/python/cpython/blob/v3.11.0/Lib/hmac.py). Реализация используемой стандартной hmac. Ссылка рядом с кодом в Инструменты/guestbook_server.py.
* Используемый API: [CPython sqlite3.Connection.backup](https://github.com/python/cpython/blob/v3.11.0/Modules/_sqlite/connection.c). Реализация используемого SQLite backup. Ссылка рядом с кодом в Инструменты/backup_guestbook.py.
* Похожая реализация: [neocities-ruby](https://github.com/neocities/neocities-ruby). Клиент API Neocities и загрузка файлов. Ссылка рядом с кодом в Инструменты/neocities-sync.mjs.
* Похожая реализация: [python-feedgen](https://github.com/lkiesow/python-feedgen). Генерация RSS/Atom. Ссылка рядом с кодом в Инструменты/build.mjs.
