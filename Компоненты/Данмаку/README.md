# Данмаку, которое можно забрать

**[Демо: скачай и открой index.html](index.html)**. Работает с диска.
Начни с index.html. Сам эффект живёт в danmaku.js, его оформление в danmaku.css.
Для запуска ничего устанавливать не нужно.

## Подключить

Скопируй danmaku.js и danmaku.css к себе. CSS в head, JS перед закрытием body:

```html
<link rel="stylesheet" href="danmaku.css">
<!-- содержимое твоего сайта -->
<script src="danmaku.js"></script>
<script>
  Danmaku.setPhrases(['привет', 'теперь оно летает']);
</script>
```

```js
Danmaku.stop();               // остановить и убрать фразы
Danmaku.start();              // включить; системное reduced motion соблюдается
Danmaku.setPhrases(['ещё']);  // заменить список
Danmaku.setLowPower(true);    // убрать эффект в облегчённом режиме
Danmaku.setLowPower(false);   // вернуть, если пользователь его не выключил
```

Загружать скрипт один раз, после body. Один экземпляр на страницу.
Интервал меняется в начале danmaku.js: messageDelay + случайная messageRandom,
оба значения в миллисекундах. По умолчанию новая попытка каждые 10–15 секунд.
Максимум две фразы, на ширине до 650px одна. Длина до 64 единиц UTF-16,
последняя половина суррогатной пары отбрасывается. Длинный текст сокращается;
это визуальный эффект, не место хранения записей.

Текст добавляется через textContent, HTML не исполняется. Фоновая вкладка
останавливает таймер. Есть автоматическая замена части RU/EN ругательств,
но это не серверная модерация и не защита от спама.

Фразы иногда идут на слое z-index:1, иногда z-index:20. Чтобы карточки
прикрывали задний слой, дай им position:relative; z-index:5; и непрозрачный фон.
Эффект не перехватывает клики. Для слабого устройства есть setLowPower(true).
Системное prefers-reduced-motion имеет приоритет над кнопкой пуска.
