# Случайный выбор без повторов / Shuffle bag

Забери shuffle-bag.js. Подключается обычным script или require в Node.
Открой index.html для демо. Ни сайта, ни пакетов не нужно.

```js
var next = createShuffleBag(['первый', 'второй', 'третий']);
console.log(next()); // все элементы по одному в случайном порядке
```

Когда пачка закончилась, она перемешивается заново. На стыке пачек повтор
исключён, если элементов больше одного. Пустой список возвращает undefined.
Один элемент неизбежно повторяется. Исходный массив не меняется.
Повторы считаются по индексам: одинаковые значения на разных позициях остаются
разными элементами, поэтому передавай уникальный список, если это важно.
Случайность Math.random, для криптографии не годится.
